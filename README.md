# Image Search and Slider

A Pixabay image-search exercise with image selection and slider creation.

**Category:** JavaScript applications

[All projects](https://github.com/maamg/maamg/blob/main/PROJECTS.md) · [Programming practice](https://github.com/maamg/jhalai)

## Open locally

Open `index.html` in a browser, or serve the repository folder:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000/index.html`. Keep the existing asset folders beside the HTML files. Internet access is needed for externally loaded fonts, styles or APIs.

## API configuration

The previously embedded API key has been replaced with a `YOUR_PIXABAY_API_KEY` placeholder in `app.js`. Configure your own provider key locally to use the demo; do not commit it. The old key remains in earlier Git history and should be revoked/rotated with the provider. No key values are included in this README. Front-end JavaScript cannot keep secrets; use provider restrictions or a server-side integration as appropriate.
